# COM Notifier

Программа живёт в системном трее и показывает стандартное уведомление Windows 10/11, когда COM-порт появляется или пропадает. Главного окна нет.

Пример уведомления:

```
🟢 Подключен COM3
USB-SERIAL CH340 (COM3)
VID:PID 1a86:7523
```

При отключении иконка 🔴 и текст «Отключен COMx». Если у порта нет VID/PID (например, встроенный COM1), выводится «VID:PID н/д».

## Иконка в трее

- **Левый клик** открывает список COM-портов по возрастанию номера: номер жирным, название устройства (обрезается по ширине, полное видно во всплывающей подсказке) и VID:PID мелким шрифтом. Закрывается кликом в любом другом месте.
- **Правый клик** открывает меню:
  - «Автозапуск при старте системы» добавляет программу в автозагрузку текущего пользователя (реестр `HKCU\...\Run`).
  - «Не повторять в течение 5 сек» скрывает повторное одинаковое уведомление (тот же порт, то же событие), если оно случилось меньше чем через 5 секунд после предыдущего. Настройка сохраняется.
  - «Пауза на 30 мин» отключает уведомления на 30 минут. Во время паузы иконка становится серой, а в пункте меню и подсказке иконки видно, сколько осталось. Снять галку можно раньше.
  - «Выход».

## Установка

1. Установите Python 3.11 с python.org (отметьте «Add python.exe to PATH»).
2. В папке программы выполните:

```
pip install -r requirements.txt
```

## Запуск

```
pythonw com_notifier.py
```

`pythonw` запускает программу без окна консоли. Вторая копия не запустится, если первая уже работает. После включения галки «Автозапуск» программа будет стартовать сама при входе в Windows.

## Сборка в один EXE

Нужен Windows с установленным Python 3.11 (сборку делают один раз, на целевых машинах Python уже не нужен).

1. Положите в одну папку `com_notifier.py`, `requirements.txt`, `icon.ico` и `build.bat`.
2. Дважды щёлкните `build.bat`. Он установит зависимости и PyInstaller и соберёт программу.
3. Готовый файл: `dist\ComNotifier.exe` (около 30–40 МБ, внутри Python и Qt). Папки `build` и файл `ComNotifier.spec` после сборки можно удалить.

EXE запускается без окна консоли, рядом с ним никаких файлов не нужно, его можно положить куда угодно. Если включить «Автозапуск» в меню, в автозагрузку пропишется путь к самому EXE, поэтому переносить его после этого не стоит (или выключите и снова включите галку на новом месте).

Где программа хранит данные:

- настройки (галка «Не повторять») в реестре: `HKEY_CURRENT_USER\Software\ComNotifier`;
- автозапуск в реестре: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`, значение `COM Notifier`;
- при каждом запуске EXE распаковывается во временную папку `%TEMP%\_MEIxxxxx`, которая удаляется при выходе. Так работает любой однофайловый EXE от PyInstaller.

Чтобы удалить программу полностью, снимите галку «Автозапуск», выйдите из программы, удалите EXE и ключ `HKEY_CURRENT_USER\Software\ComNotifier`.

Однофайловые EXE от PyInstaller иногда ошибочно помечаются антивирусом (в том числе Защитником Windows). Если это случилось, добавьте файл в исключения.

## Если уведомления не появляются

Проверьте, что уведомления включены: Параметры → Система → Уведомления (для Python), а также что не включён режим «Не беспокоить» (Фокусировка внимания).
